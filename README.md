# 时序 Atlas

全球城市时间与公共假日日历。纯静态 HTML、CSS、JavaScript，无需账号登录。

## 功能
- 世界时钟、夏令时、城市搜索和浏览器本地收藏
- 国家与年份选择、月历、全国及地区公共假日
- 手机浏览适配

## 数据
- 设备时间及浏览器 Intl/IANA 时区
- 时区元数据：moment-timezone data/meta/latest.json
- 公共假日：https://date.nager.at （需网络连接；以服务支持范围及当地官方公告为准）

## 本地预览
在本目录启动任意静态 HTTP 服务器。不要直接双击 index.html，因为浏览器可能阻止读取本地 JSON。

## GitHub Pages
Settings → Pages → Deploy from a branch → main → / (root)。

## 国家时间海报与新闻
顶部海报从 246 个国家和地区中随机选择，每 60 秒切换，可暂停或手动选国家。时间以所标注代表城市的 IANA 时区计算，支持夏令时。

海报图片保存在 assets/，来源链接随海报显示（Wikipedia/Wikimedia Commons；作者和许可见对应来源页面）。

新闻为 Google News RSS 近 7 天的最多 12 条报道标题、来源、时间和原文入口，不抓取正文，也不声称覆盖所有事件。scripts/update-news.cjs 更新 news.json；失败时沿用可用快照并标明时间。

.github/workflows/pages.yml 在推送、手动运行和每 3 小时更新新闻并发布 Pages。定时任务可能延迟，以页面显示的更新时间为准。可在仓库 Actions 中查看更新状态。

## 全部国家海报（2026-10-27）
海报扩展为 246 个有代表城市的国家和地区；照片均保存在 assets/，图片、当地时钟和对应新闻在切换时同步更新。无人居住且没有代表城市的地区不单列城市海报。

local-news-sources.json 为每个国家配置语言、当地媒体域名和国家主题词。优先读取该国版的国内新闻 RSS，再验证发布者来源域名；无合适结果时仅查询当地来源。不使用中国版中文新闻作为其他国家的后备数据。新闻保持媒体原文，不自动翻译。共享商业域名（例如 .ai、.io、.tv）不能单独作为当地媒体归属依据。

部分国家或地区没有可抓取的当地报道时会明确显示暂无数据，不用国际媒体或虚构内容填充。域名筛选用于媒体来源归类，不能保证覆盖所有当地媒体或所有新闻事件。

## 多语言、IP 与新闻详情（2026-10-27）
- languages.json 提供在线翻译服务当次返回的 249 个目标语言选项，并非世界上所有现存语言。用户可在右上角搜索语言；手动选择优先并保存在浏览器。
- 首次语言根据 IP 国家选择；识别失败回退浏览器语言。IP 查询使用 ipapi.co 和 api.country.is，IP 与识别到的时区仅供当前页面展示，应用不把 IP 写入仓库或本地存储；接口不可用时显示查询失败并使用设备时区。
- i18n.js 对界面及新闻标题按需请求在线机器翻译，使用浏览器缓存；失败明确保留原文。当前公共翻译入口无服务可用性保证，生产稳定使用可替换成自有翻译代理和正式服务凭证。
- article.html 为本站新闻索引详情页，包含翻译标题、原始标题、媒体与发布时间和可用摘要入口。没有授权不复制媒体全文；来源没有摘要时明确显示缺失。点击索引不会冒充已经转载完整新闻。
- 卡片标题改为世界时间；city-images.json 匹配到的 305 个城市/时区增加对应实景图片，无法匹配时不使用其他城市照片冒充。日间乳白色文字，夜间灰色文字。图片来源统一可查 image-credits.html。
