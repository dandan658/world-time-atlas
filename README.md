# 时序 Atlas · 世界时间

静态世界时钟、黑白灰城市海报和公共假日日历。

## 功能
- 海报指针钟居中，数字时间位于下方。根据代表城市当地时间，日间使用白色表盘与黑色指针，夜间使用黑色表盘与白色指针。
- 全站黑白灰配色，海报背景以灰度与模糊处理。
- 246 个国家和地区，可手动选择或随机切换。时区由 IANA / Intl 计算。
- 图片时钟卡片、搜索、收藏、公共假日日历。
- 249 个在线翻译语言选项、IP 国家语言识别、IP / 时区 / 日期时间展示。外部服务失败时保留可用信息。
- 景点图来源及许可入口见 image-credits.html。

## 部署
GitHub Actions 在推送或手动运行时发布静态文件。无后台抓取任务。

## 数据
公共假日：Nager.Date（覆盖因国家和年份而异，以当地官方公告为准）。
国家与时区元数据：moment-timezone / IANA。
图片：Wikipedia / Wikimedia Commons。

2026-10-27：已删除站点新闻数据、详情页、抓取脚本、来源配置及定时更新任务；浏览器旧新闻缓存会在打开新版本时清理。保留 Git 提交历史作为代码版本记录。

## 页面与图片
- 首页仅显示海报和世界时间卡片；calendar.html 为独立公共假日日历页面。导航链接直接跳转。
- 海报文字设置 user-select:none，并阻止页面内选中文字的复制事件；这属于界面交互限制，不是内容加密。
- 全部图片统一以 WebP 保存并在黑白灰界面中展示。landmarks.json 记录景点和真实所在地，city-images.json 对应各时区的景点图片；图片所在地与时钟城市不相同时，卡片标明图片的实际所在地。

2026-10-27 界面更新：海报居中，数字时间位于指针钟下方，黑白表盘按当地日间/夜间切换。日历独立为 calendar.html，导航栏跨页跳转。海报文字不可选中复制，所有使用中的 260 张图片为 WebP。418 个时区卡片均配置本国景点图或对应南极站点图；没有使用其他国家图片替代。

时钟卡片保留彩色景点照片及深绿色遮罩；仅海报使用灰度模糊背景和昼夜黑白表盘。
